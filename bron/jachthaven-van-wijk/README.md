# jachthaven-van-wijk

Ontwerpvoorstel (Astro 7 + Tailwind 4) voor Jachthaven van Wijk, Woubrugge.

    npm install
    PUBLIC_VOORSTEL=1 npx astro build
    npx astro preview --port 4482   # http://localhost:4482/sitefront/jachthaven-van-wijk/

Feiten: zie de bronregel in src/data/site.ts. Foto's: src/assets/BRONNEN.txt. Screenshots en Lighthouse: shots/.
