# mogo-autopoets-meerkerk

Ontwerpvoorstel (Astro 7 + Tailwind 4) voor MoGo Autopoetsbedrijf, Meerkerk. Bouwen: `PUBLIC_VOORSTEL=1 npx astro build`,
bekijken: `npx astro preview --port 4703` → http://localhost:4703/sitefront/mogo-autopoets-meerkerk/

Ontbreekt nog (niet zichtbaar op de site, alleen op de privacypagina gemarkeerd):
- bewaartermijn gegevens (privacy)
- actuele prijzen / pakketten (servicepakketten 1-3 bestaan volgens een post, inhoud onbekend)
- eigen foto van de werkplaats in Meerkerk en van Tygo/het team
- bevestiging dat Gorinchemsestraat 1B de werkplaats is (KvK-zetel is Noordeloos)
