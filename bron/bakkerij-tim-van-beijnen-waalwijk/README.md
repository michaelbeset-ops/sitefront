# bakkerij-tim-van-beijnen-waalwijk
Ontwerpvoorstel (Astro + Tailwind 4) voor Tim van Beijnen patisserie boulangerie ("Van Tim"), Hoogeinde 18a Waalwijk.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4402`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, map bron/.
