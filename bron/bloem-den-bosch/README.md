# bloem-den-bosch

Ontwerpvoorstel (Astro 7 + Tailwind 4) voor Bloem, Engels theehuisje in het Prins Hendrikpark, 's-Hertogenbosch.

    npm install
    PUBLIC_VOORSTEL=1 npx astro build   # met voorstelbalk en noindex
    npx astro preview --port 4503

Feiten: src/data/site.ts en src/scripts/open.ts (openingstijden). Wow: src/components/Langskomen.astro. Foto's: src/assets/BRONNEN.txt.
