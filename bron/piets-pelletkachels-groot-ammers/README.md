# piets-pelletkachels-groot-ammers
Ontwerpvoorstel (Astro + Tailwind 4) voor Piet's Pelletkachels, Houtkachels & Haarden, Voorstraat 55A Groot-Ammers.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4404`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, map bron/.
