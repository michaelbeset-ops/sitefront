# sportmassage-barendrecht
Ontwerpvoorstel (Astro 7 + Tailwind 4, Archivo + Public Sans). Bouwen: `PUBLIC_VOORSTEL=1 npx astro build`, bekijken: `npm run preview` (poort 4675).
Bronnen van foto's: src/assets/BRONNEN.txt. Feiten: src/data/site.ts (bronregel bovenaan). Ruwe scrape: scratchpad/b23/smb (reviews: google-reviews.txt).

- Tijden: Google zegt ma-vr 10.00-22.00, za 10.00-20.00; hun eigen site zegt ma-vr 10.00-16.00 en 19.00-22.00, za/zo gesloten. De demo volgt Google. Navragen.
- Prijzen: niet gepubliceerd (alleen verzendkosten cadeaubon € 5,35). Op de site: "Vraag naar de prijzen via WhatsApp".
- KvK-nummer (niet getoond), eigen foto's van de praktijkruimte en van Andrea (Google heeft alleen 2 sfeerfoto's en Street View).
- Bewaartermijn gegevens (privacypagina, gemarkeerd).
- Google-reviews: alleen 3 van 11 zichtbaar zonder inloggen. Gastenboeknamen ingekort tot voornaam + initiaal; even akkoord vragen.
