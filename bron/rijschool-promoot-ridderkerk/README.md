# rijschool-promoot-ridderkerk

Ontwerpvoorstel (Astro 7 + Tailwind 4) voor Rijschool Promoot, Ridderkerk. Zie PLAN.md.

    npm install
    PUBLIC_VOORSTEL=1 npx astro build
    npx astro preview --port 4713   # http://localhost:4713/sitefront/rijschool-promoot-ridderkerk/
    node tools/shots.mjs fin        # screenshots in shots/
    node tools/og.mjs               # public/og.jpg
