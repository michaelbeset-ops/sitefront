# mrvie-detailing-barendrecht

Ontwerpvoorstel (Astro 7 + Tailwind 4). Build: `PUBLIC_VOORSTEL=1 npx astro build`, preview op poort 4643.
Screenshots: `node tools/shots.mjs <prefix>`, og-beeld: `node tools/og.mjs`, WhatsApp-test: `node tools/watest.mjs`.

## Ontbreekt / navragen bij de klant
- KvK-nummer (alleen gemarkeerd op de privacypagina; footer laat het weg).
- Bewaartermijn gegevens (privacypagina).
- Kloppen de pakketprijzen van mrvie.nl (archief mei 2026) nog?
- Zaterdag in Numansdorp (Edisonstraat 84a, oude site) of in Barendrecht (Google)?
- Eigen foto's in hogere resolutie (Instagram-foto's zijn 640px) en eventueel een eigen hero-foto van een zwarte auto in de lak.
