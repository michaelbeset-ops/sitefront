# mrvie-detailing-barendrecht

Ontwerpvoorstel (Astro 7 + Tailwind 4). Build: `PUBLIC_VOORSTEL=1 npx astro build`, preview op poort 4691.
Screenshots: `node tools/shots.mjs <prefix>`, og-beeld: `node tools/og.mjs`, test voor/na + WhatsApp: `node tools/watest.mjs`.
