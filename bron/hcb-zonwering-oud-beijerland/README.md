# hcb-zonwering-oud-beijerland
Ontwerpvoorstel (Astro + Tailwind 4) voor HCB Zonwering, Zinkweg 97 Oud-Beijerland.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4443`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, map bron/, PLAN.md.
