# repti-farm-ridderkerk
Ontwerpvoorstel (Astro 7 + Tailwind 4, Archivo + Inter). Bouwen: `PUBLIC_VOORSTEL=1 npx astro build`, bekijken: `npm run preview` (poort 4662).
Bronnen: /bron (oude site, Google-profiel, reviews, Facebook), foto's: src/assets/BRONNEN.txt, feiten: src/data/site.ts.

## Ontbreekt (aanleveren door Repti-Farm)
- Actuele foto's van winkel, kelder en visafdeling in hoge resolutie (oude site: 450px; geen foto van de visafdeling).
- Welke dieren er nu te koop zijn; eventuele prijzen (nergens gepubliceerd).
- Bewaartermijn voor de privacyverklaring. Logo als vectorbestand.
