# rosa-gorinchem
Ontwerpvoorstel (Astro + Tailwind 4) voor Rosa, exclusieve kleding & curiosa, Burgstraat 10 Gorinchem.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4394`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, map bron/.
