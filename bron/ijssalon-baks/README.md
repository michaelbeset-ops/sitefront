# ijssalon-baks

Ontwerpvoorstel van Sitefront voor IJs & Spijssalon Baks (Woudrichem en Raamsdonksveer). Astro 7 + Tailwind 4.

    npm install
    PUBLIC_VOORSTEL=1 npx astro build   # voorstelmodus: balk, noindex, formulieren versturen niets
    npx astro preview --port 4437       # http://localhost:4437/sitefront/ijssalon-baks/
