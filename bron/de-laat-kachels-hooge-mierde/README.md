# de-laat-kachels-hooge-mierde
Ontwerpvoorstel (Astro + Tailwind 4) voor De Laat Kachels & Haarden, Kailakkers 2c Hooge Mierde.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4412`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, map bron/.
