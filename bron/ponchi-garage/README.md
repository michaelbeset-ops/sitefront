# ponchi-garage

Ontwerpvoorstel van Sitefront voor Ponchi Garage, Daltonstraat 14, Dordrecht. Astro 7 + Tailwind 4.

- `npm run dev` om lokaal te bekijken
- `PUBLIC_VOORSTEL=1 npx astro build` voor de voorstelversie (voorstelbalk, noindex, formulier verstuurt niets)
- Feiten: `src/data/site.ts`. Fotobronnen: `src/assets/BRONNEN.txt`. Zie ook `PLAN.md`.
