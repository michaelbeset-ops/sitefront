# kaffee-de-bonnefooi-dinteloord
Ontwerpvoorstel (Astro + Tailwind 4) voor Kaffee de Bonnefooi, Stoofdijk 26 Dinteloord.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4396`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, map bron/.
