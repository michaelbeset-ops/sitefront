# minicamping-t-hommeltje

Ontwerpvoorstel van Sitefront (Astro 7 + Tailwind 4). `npm run dev` om lokaal te draaien;
`PUBLIC_VOORSTEL=1 npx astro build` voor de voorstelversie (voorstelbalk, noindex, formulier verstuurt niets).
Bronnen van feiten staan bovenaan `src/data/site.ts`, van foto's in `src/assets/BRONNEN.txt`.
