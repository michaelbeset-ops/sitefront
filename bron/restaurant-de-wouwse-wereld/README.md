# restaurant-de-wouwse-wereld

Ontwerpvoorstel (Astro 7 + Tailwind 4) voor Restaurant De Wouwse Wereld in Wouw.

    npm install
    PUBLIC_VOORSTEL=1 npx astro build   # met voorstelbalk en noindex
    npx astro preview --port 4436

Feiten: src/data/site.ts (menukaart) en src/scripts/open.ts (openingstijden en vakantie). Foto's: src/assets/BRONNEN.txt.
