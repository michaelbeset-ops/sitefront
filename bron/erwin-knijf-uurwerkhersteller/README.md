# erwin-knijf-uurwerkhersteller

Ontwerpvoorstel (Astro 7 + Tailwind 4) voor Uurwerkhersteller Erwin Knijf. Concept: gesigneerde emaille wijzerplaat
(src/components/Wijzerplaat.astro, loopt mee met de echte tijd). Zie PLAN.md.

    npm install
    PUBLIC_VOORSTEL=1 npx astro build  # met voorstelbalk en noindex
    npx astro preview --port 4558
