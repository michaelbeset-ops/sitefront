# wk-rijopleidingen-hia

Ontwerpvoorstel (Astro 7 + Tailwind 4) voor WK Rijopleidingen, Hendrik-Ido-Ambacht.

    PUBLIC_VOORSTEL=1 npx astro build
    npx astro preview --port 4711   # http://localhost:4711/sitefront/wk-rijopleidingen-hia/

tools/: shots.mjs (screenshots + scrollWidth), ovf.mjs (overflow), reken.mjs (rekenhulp-test), og.mjs (public/og.jpg),
blur.cjs (kentekens vervagen), sheet.cjs (contactsheets). Zie PLAN.md.
