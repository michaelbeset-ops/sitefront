# maximum-detailing-ridderkerk

- Bouwen: `PUBLIC_VOORSTEL=1 npx astro build`; bekijken: `npx astro preview --port 4663`
- Screenshots: `node tools/shots.mjs <prefix>`; og: `node tools/og.mjs`
