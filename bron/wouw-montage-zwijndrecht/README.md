# wouw-montage-zwijndrecht
Ontwerpvoorstel (Astro + Tailwind 4) voor Wouw Montage, Marsmanstraat 2 Zwijndrecht.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4450` (4440 was bezet door een oude stremme-preview).
Bronnen: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, PLAN.md, map bron/.
