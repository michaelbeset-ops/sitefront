# effe-anders-steenbergen

Ontwerpvoorstel (Astro 7 + Tailwind 4) voor Effe Anders, Surinaams eethuis aan de Markt in Steenbergen.
Concept: hun etalageruit en zwarte menukaart. Rode hoekige raamletters (Squada One) + Archivo, de Surinaamse vlagbaan als ornament.
Base: /sitefront/effe-anders-steenbergen.

    npm install
    PUBLIC_VOORSTEL=1 npx astro build  # met voorstelbalk en noindex
    npx astro preview --port 4533

Feiten: src/data/site.ts (Google-profiel, hun site, menukaart-PDF 2022; prijzen bewust weggelaten). Foto's: src/assets/BRONNEN.txt.
og.jpg is gemaakt met scratchpad/pw/effe-og.mjs.
