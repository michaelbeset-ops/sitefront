# maso-barbershop-ridderkerk
Demo (Astro + Tailwind 4) voor Maso Hair Salon & Barbershop, Dillenburgplein 4, Ridderkerk.
- Voorstelmodus bouwen: `PUBLIC_VOORSTEL=1 npx astro build`, bekijken: `npx astro preview --port 4632`
- Screenshots: `node tools/shots.mjs <prefix>`; og-afbeelding: `node tools/og.mjs`
