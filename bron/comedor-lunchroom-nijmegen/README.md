# comedor-lunchroom-nijmegen
Ontwerpvoorstel (Astro + Tailwind 4) voor Comedor Lunchroom, Van Welderenstraat 77 Nijmegen + Johan de Wittlaan 271 Arnhem.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4399`.
Bronnen: src/data/site.ts (commentaar), PLAN.md, map bron/. Herofoto: bovenste 420px van bron/gfoto-nij/a-10.jpg weggesneden (hand van een gast).
