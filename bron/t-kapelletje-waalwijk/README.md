# t-kapelletje-waalwijk
Ontwerpvoorstel (Astro + Tailwind 4) voor Restaurant 't Kapelletje, Kloosterweg 71, Waalwijk.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, bekijken: `npx astro preview --port 4397`.
Bronnen en bewijs: `bron/`, fotobronnen: `src/assets/BRONNEN.txt`, plan en mankementen: `PLAN.md`.
