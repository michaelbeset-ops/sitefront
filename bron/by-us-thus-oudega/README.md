# by-us-thus-oudega

Ontwerpvoorstel (Astro 7 + Tailwind 4) voor Restaurant By ús thús in Oudega.

    npm install
    PUBLIC_VOORSTEL=1 npx astro build   # met voorstelbalk en noindex
    npx astro preview --port 4500

Feiten: src/data/site.ts en src/scripts/open.ts. Foto's: src/assets/BRONNEN.txt.
