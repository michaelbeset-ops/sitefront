# autobedrijf-motech-arkel
Ontwerpvoorstel (Astro 7 + Tailwind 4) voor Autobedrijf MOTECH, Arkel. Build: `PUBLIC_VOORSTEL=1 npx astro build`,
preview: `npx astro preview --port 4742` -> http://localhost:4742/sitefront/autobedrijf-motech-arkel/
Tools: tools/shots.mjs (screenshots + scrollWidth), tools/og.mjs (public/og.jpg), tools/watest.mjs (APK-wijzer), tools/ovf.mjs.
