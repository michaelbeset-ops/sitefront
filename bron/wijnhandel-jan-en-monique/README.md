# wijnhandel-jan-en-monique

Ontwerpvoorstel (Astro 7 + Tailwind 4) voor Wijnhandel & Slijterij Jan & Monique, Ridderkerk.

    npm install
    PUBLIC_VOORSTEL=1 npx astro build   # voorstelmodus: voorstelbalk, noindex, formulier verstuurt niets
    npx astro preview --port 4431

Base: /sitefront/wijnhandel-jan-en-monique. Feiten staan in src/data/site.ts, fotobronnen in src/assets/BRONNEN.txt.
