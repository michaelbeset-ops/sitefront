# grandcafe-mn-moeder-leerdam
Ontwerpvoorstel (Astro + Tailwind 4) voor Grandcafé M'n Moeder, Kerkstraat 33a Leerdam.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4415`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, PLAN.md, map bron/.
