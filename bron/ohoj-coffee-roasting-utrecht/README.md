# ohoj-coffee-roasting-utrecht
Ontwerpvoorstel (Astro + Tailwind 4) voor Ohøj Coffee Roasting, Rijnlaan 27 Utrecht.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4417`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, PLAN.md, map bron/.
