# genieten-vianen
Ontwerpvoorstel (Astro + Tailwind 4) voor Genieten, delicatessen & lifestyle, Voorstraat 63 Vianen.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4407`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, map bron/.
