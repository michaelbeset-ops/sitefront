# bas-van-der-ven-catering-etten-leur
Ontwerpvoorstel (Astro + Tailwind 4) voor Bas & Anneloes (op Google nog "Bas van der Ven Catering"), Korte Brugstraat 98 Etten-Leur.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4400`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, map bron/.
