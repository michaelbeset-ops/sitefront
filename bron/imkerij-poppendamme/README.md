# imkerij-poppendamme

Ontwerpvoorstel van Sitefront voor Imkerij Poppendamme (Grijpskerke). Astro 7 + Tailwind 4.

    npm install
    PUBLIC_VOORSTEL=1 npx astro build   # demomodus: voorstelbalk, noindex
    npx astro preview --port 4435       # http://localhost:4435/sitefront/imkerij-poppendamme/
