 Special tools, hydraulic jack set for Deutz 628 and 540 engine
 “Can you find a special tools set with the hydraulic jacks for tightening and release of cylinder head and main bearing bolts for Deutz engines of 20 years old?” 
 A nice challenge. We have offered this set a couple of times to different ship owners and this time client could confirm the order. The set was originally supplied with a new engine years ago and kept on board for emergency use. When the Deutz engine was changed the crew on board didn’t even know that they had it on board. The jack set was never used. So after replacing sealing’s and pipework we had an almost new set available. We arranged a toolbox suitable for the complete set and send it off to our client.
