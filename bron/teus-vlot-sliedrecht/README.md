# teus-vlot-sliedrecht
Ontwerpvoorstel (Astro + Tailwind 4) voor de Teus Vlot Groep / Teus Vlot Diesel & Marine, Baanhoek 182b Sliedrecht.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4420`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, map bron/. Concept en bewijs: PLAN.md.
