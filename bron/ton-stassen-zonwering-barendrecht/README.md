# ton-stassen-zonwering-barendrecht
Ontwerpvoorstel (Astro + Tailwind 4) voor Ton Stassen Zonwering & outdoor Living, Middeldijk 56A Barendrecht.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4444`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, map bron/.
