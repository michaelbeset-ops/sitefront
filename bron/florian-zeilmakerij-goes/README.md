# florian-zeilmakerij-goes

Ontwerpvoorstel (Astro 7 + Tailwind 4) voor Florian Zeilmakerij in Goes. Concept: stalenboek van kappendoek. Zie PLAN.md.

    npm install
    PUBLIC_VOORSTEL=1 npx astro build  # met voorstelbalk en noindex
    npx astro preview --port 4557
