# schoenmaker-toon
Ontwerpvoorstel (Astro + Tailwind 4) voor Uw Schoenmaker Toon, Middelharnis. Base `/sitefront/schoenmaker-toon`.
- Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`; bekijken: `npx astro preview --port 4623`.
- Beelden opnieuw maken: `node tools/beelden.mjs` (bron/ = eigen Google-foto's); og.jpg: `node tools/og.mjs`; shots: `node tools/shots.mjs <prefix>`.
