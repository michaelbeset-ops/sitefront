# terlouw-interieur-hia
Ontwerpvoorstel (Astro + Tailwind 4) voor Terlouw Interieur & Montage, showroom Bruningsstraat 17 Werkendam.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4449`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, map bron/.
