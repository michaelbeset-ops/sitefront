# nellies-private-dining-tholen
Ontwerpvoorstel (Astro + Tailwind 4) voor Nellie's private dining, Oudelandsedijk 6 Tholen.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4395`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, map bron/.
