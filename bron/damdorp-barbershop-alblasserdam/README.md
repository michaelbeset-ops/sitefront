# damdorp-barbershop-alblasserdam

Ontwerpvoorstel (Astro + Tailwind 4) voor Damdorp Barbershop. Bouwen in demomodus:

    PUBLIC_VOORSTEL=1 npx astro build && npx astro preview --port 4635

Tools: `tools/hero.mjs` (hero met vervaagde merkopdruk), `tools/og.mjs` (public/og.jpg), `tools/shots.mjs <prefix>` (screenshots).
Bronmateriaal in `bron/`, fotobronnen in `src/assets/BRONNEN.txt`.
