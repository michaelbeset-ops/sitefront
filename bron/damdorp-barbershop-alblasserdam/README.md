# damdorp-barbershop-alblasserdam

Ontwerpvoorstel (Astro + Tailwind 4) voor Damdorp Barbershop. Bouwen in demomodus:

    PUBLIC_VOORSTEL=1 npx astro build && npx astro preview --port 4682

Tools: `tools/prep.mjs` en `tools/prep-hero.mjs` (beelden klaarzetten), `tools/og.mjs` (public/og.jpg), `tools/shots.mjs <prefix>` (screenshots).
Bronmateriaal in `bron/`, fotobronnen in `src/assets/BRONNEN.txt`.
