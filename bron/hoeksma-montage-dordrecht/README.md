# hoeksma-montage-dordrecht
Ontwerpvoorstel (Astro + Tailwind 4) voor J. Hoeksma Montage & Timmerwerken, Dordrecht.
- Bouwen als voorstel: `PUBLIC_VOORSTEL=1 npx astro build` (voorstelbalk, noindex).
- Preview: `npx astro preview --port 4622` op /sitefront/hoeksma-montage-dordrecht/.
- Gegevens: src/data/site.ts; foto's en teksten van het werk: src/data/werk.ts.
