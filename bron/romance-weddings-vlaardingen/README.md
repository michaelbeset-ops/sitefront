# romance-weddings-vlaardingen
Ontwerpvoorstel (Astro + Tailwind 4) voor Romance Weddings & Events (Partycentrum Romance B.V.), Koningin Wilhelminahaven ZZ 13, Vlaardingen.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4403`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, map bron/ (site/ en google/).
