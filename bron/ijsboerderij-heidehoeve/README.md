# ijsboerderij-heidehoeve

Ontwerpvoorstel van Sitefront voor IJsboerderij Heidehoeve (Etten-Leur). Astro 7 + Tailwind 4.

    npm install
    PUBLIC_VOORSTEL=1 npx astro build
    npx astro preview --port 4439

Feiten staan in `src/data/site.ts`, fotobronnen in `src/assets/BRONNEN.txt`, keuzes in `PLAN.md`.
