# autocorner-zuid-beijerland

Demo-site (Astro 7 + Tailwind 4) voor Autocorner Zuid-Beijerland B.V.

    npm install
    PUBLIC_VOORSTEL=1 npx astro build   # voorstelmodus: balk bovenaan, noindex, formulier verstuurt niets
    npx astro preview --port 4421

Base: /sitefront/autocorner-zuid-beijerland. Zie PLAN.md voor bronnen en keuzes.
