# marcus-coffee-vlissingen
Ontwerpvoorstel (Astro + Tailwind 4) voor Marcus Coffee, Tea Blends & Lifestyle, Bellamypark 52 Vlissingen.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4410`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, PLAN.md, map bron/.
