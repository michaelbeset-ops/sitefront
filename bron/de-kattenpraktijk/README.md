# de-kattenpraktijk

Ontwerpvoorstel (Astro 7 + Tailwind 4) voor De Kattenpraktijk, Capelle aan den IJssel.

```bash
npm install
PUBLIC_VOORSTEL=1 npx astro build   # voorstelversie (voorstelbalk, noindex)
npx astro preview --port 4470       # http://localhost:4470/sitefront/de-kattenpraktijk/
```
Zie PLAN.md en src/assets/BRONNEN.txt.
