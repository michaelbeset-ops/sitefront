# fadis-rotterdam

Ontwerpvoorstel (Astro 7 + Tailwind 4) voor Fadi's Eten & Drinken, Turks lunchtentje op het Noordereiland, Rotterdam.
Concept: het groene terrastafeltje bij de hoge ramen, het ruitlogo van het raam en het eiland als kaartje. Zie PLAN.md.

    npm install
    PUBLIC_VOORSTEL=1 npx astro build  # met voorstelbalk en noindex
    npx astro preview --port 4543

Feiten: src/data/site.ts en src/scripts/open.ts (openingstijden). Foto's: src/assets/BRONNEN.txt.
Eiland: src/data/eiland.ts (OpenStreetMap-contour).
