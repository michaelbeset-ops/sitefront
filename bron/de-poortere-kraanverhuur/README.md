# de-poortere-kraanverhuur

Ontwerpvoorstel (Astro 7 + Tailwind 4) voor De Poortere Kraanverhuur B.V., Waarde.

- `npm run dev` lokaal, `PUBLIC_VOORSTEL=1 npx astro build` voor de voorstelversie (voorstelbalk, noindex).
- Base: `/sitefront/de-poortere-kraanverhuur`. Testpoort 4492.
- Feiten staan in `src/data/site.ts`; foto-bronnen in `src/assets/BRONNEN.txt`.
