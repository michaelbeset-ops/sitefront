# schilderwerken-radi
Ontwerpvoorstel (Astro 7 + Tailwind 4). Bouwen: `PUBLIC_VOORSTEL=1 npx astro build`, bekijken: `npm run preview` (poort 4642).
Bronnen van foto's: src/assets/BRONNEN.txt. Feiten: src/data/site.ts (bronregel bovenaan).

## Ontbreekt (bij oplevering navragen)
- KvK-nummer (alleen op de privacypagina gemarkeerd).
- Of het mailadres schilderwerkenradi@hotmail.com nog werkt (komt van de site uit 2020).
- Bevestiging dat Karim de eigenaar/aanspreekpunt is (naam uit reviews en de oude referentiepagina; WhatsApp begint met "Hallo Karim").
- Huisadres bewust weggelaten (privé); alleen Hendrik-Ido-Ambacht en werkgebied Drechtsteden.
- Prijzen, jaartallen, keurmerken: niet bekend, niet getoond.
- Betere/grotere foto's van recent werk (huidige zijn telefoonfoto's, max 1600px).
